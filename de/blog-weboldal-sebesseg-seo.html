Warum ist deine Website langsam — und warum interessiert das Google?

4. September 2026 · 2 Min. Lesezeit

Website-Geschwindigkeit ist keine technische Kleinigkeit — sie wirkt direkt auf den Umsatz. Von einer langsamen Seite klicken die Leute weg, bevor sie geladen ist, und Google stuft sie zurück. Schauen wir, warum, und was du tun kannst.

Warum zählt Geschwindigkeit?

  • Der Besucher: Ein erheblicher Teil der Besucher verlässt die Seite, wenn sie nicht in wenigen Sekunden lädt. Jede zusätzliche Sekunde kostet Conversions.
  • Google: Die Suchmaschine berücksichtigt die Nutzererfahrung (Core Web Vitals — Ladezeit, Interaktivität, visuelle Stabilität) auch als Rankingfaktor. Eine langsame Seite startet im Nachteil.

Was bremst die meisten Seiten?

  • Zu große Bilder: der häufigste Übeltäter. Ein unbearbeitetes Foto mit mehreren Megabyte zieht die Ladezeit unnötig in die Länge.
  • Viele und schwere Skripte: Jedes Plugin, jedes eingebettete Widget und jeder Tracking-Code bremst. Hier ist weniger tatsächlich mehr.
  • Langsames oder überlastetes Hosting: Ein billiger, überfüllter Server bremst auch den besten Code aus.
  • Kein Cache: Wenn die Seite für jeden Besucher von Grund auf neu aufgebaut wird, arbeitet sie unnötig.
  • Render-blockierende Ressourcen: CSS oder JS, das die Darstellung anhält, bis es geladen ist.

Wie misst du das?

Googles PageSpeed Insights (pagespeed.web.dev) ist ein kostenloses, verlässliches Werkzeug — du gibst die URL ein und bekommst einen Wert für Mobil und Desktop plus konkrete Empfehlungen. Schau immer zuerst auf Mobil: von dort kommen die meisten Besucher.

Schnelle Gewinne

  • Optimiere die Bilder: passende Größe, modernes Format (etwa WebP), Komprimierung. Das allein bringt viel.
  • Lazy Loading: Bilder weiter unten sollen erst laden, wenn der Besucher dorthin scrollt.
  • Weniger Plugins und Skripte: Lösch, was du nicht nutzt. Jede Einbettung wird mit Geschwindigkeit bezahlt.
  • Cache und CDN: Zwischenspeicher und Content Delivery Network bringen die Seite näher an den Besucher.
  • Gutes Hosting: Wenn alles optimiert ist und es trotzdem langsam bleibt, ist der Server der Engpass.

Das Wesentliche

Geschwindigkeit ist Geld: eine schnellere Seite bedeutet mehr bleibende Besucher, ein besseres Google-Ranking und mehr Anfragen. Fang bei den Bildern und den überflüssigen Skripten an — auf den meisten Seiten machen diese beiden den Großteil der Verbesserung aus. Wenn du lieber von Grund auf baust: so bauen wir Websites.
