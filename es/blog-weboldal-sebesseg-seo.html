¿Por qué tu web es lenta y por qué le importa a Google?

4 de septiembre de 2026 · 2 min de lectura

La velocidad de una web no es un detalle técnico: afecta directamente a los ingresos. De una web lenta la gente se marcha antes de que cargue, y Google además la posiciona más abajo. Veamos por qué y qué puedes hacer.

¿Por qué importa la velocidad?

  • El visitante: una parte importante de las visitas abandona la web si no carga en unos segundos. Cada segundo de más cuesta conversiones.
  • Google: el buscador también tiene en cuenta la experiencia de usuario (Core Web Vitals — carga, interactividad, estabilidad visual) como factor de posicionamiento. Una web lenta parte en desventaja.

¿Qué frena a la mayoría de webs?

  • Imágenes demasiado grandes: el culpable más habitual. Una foto sin procesar de varios megabytes alarga la carga sin necesidad.
  • Demasiados scripts pesados: cada plugin, cada widget incrustado y cada código de seguimiento ralentiza. Aquí menos es de verdad más.
  • Hosting lento o saturado: un servidor barato y masificado frena incluso el mejor código.
  • Sin caché: si la página se reconstruye desde cero para cada visitante, está trabajando de más.
  • Recursos que bloquean el renderizado: CSS o JS que detiene la visualización hasta que termina de cargar.

¿Cómo medirlo?

PageSpeed Insights de Google (pagespeed.web.dev) es una herramienta gratuita y fiable: introduces la URL y obtienes una puntuación para móvil y escritorio más recomendaciones concretas. Mira siempre primero el móvil: de ahí viene la mayoría de las visitas.

Victorias rápidas

  • Optimiza las imágenes: tamaño adecuado, formato moderno (por ejemplo WebP), compresión. Solo esto ya cambia mucho.
  • Carga diferida (lazy load): que las imágenes de más abajo carguen solo cuando el visitante llegue a ellas.
  • Menos plugins y scripts: borra lo que no uses. Cada incrustación se paga en velocidad.
  • Caché y CDN: la caché y la red de distribución de contenido acercan la web al visitante.
  • Buen hosting: si ya lo has optimizado todo y sigue lenta, el cuello de botella es el servidor.

Lo esencial

La velocidad es dinero: una web más rápida significa más visitas que se quedan, mejor posición en Google y más consultas. Empieza por las imágenes y los scripts innecesarios — en la mayoría de webs esos dos elementos suponen el grueso de la mejora. Si prefieres construir desde cero: así hacemos webs.
